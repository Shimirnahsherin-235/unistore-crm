# UniStore CRM

A retail CRM built with Python, Streamlit and SQLite. The data model is generic, so any retail business (grocery, clothing, pharmacy) can use it.

## Features
- Manage stores, customers and products
- Billing with multiple items per bill
- Dashboard: sales by store, top 5 customers
- Import stores, products, customers and bills from CSV (see sample_data)
- Delete records (blocked when bills depend on them)
- Customer insights: profile, inactive customers, co-purchase next-product score

## Run
pip install -r requirements.txt
streamlit run app.py

Delete crm.db for a clean start. The tables are created automatically.

## Sample data
The demo data in crm.db is fake data generated by seed.py (Faker library). Files in sample_data/ show the CSV format for importing stores, products, customers and bills.

## Future scope
Inventory and stock tracking, GST and discounts, user login and roles, Excel import, faster batch import for large files, PostgreSQL for multi-store scale.
